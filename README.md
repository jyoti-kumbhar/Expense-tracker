# Ledger — Expense Tracker

A clean, fast, and modern cross-platform expense tracking mobile application built with **React Native**, **Expo**, and **TypeScript**.

---

## 📱 Features

- **Dashboard & Overview**: Quick glance at your total balance, monthly spending, and budget status.
- **Expense CRUD**: Add, edit, delete, and categorize daily expenses with notes and payment methods.
- **Budget Tracking**: Set overall and per-category monthly spending limits with progress indicators.
- **Analytics & Reports**: Visual reports with 7-day breakdowns, category totals, and monthly trends.
- **Data Export & Import**: Backup and export your financial records directly to CSV.
- **Dark & Light Mode**: Seamless theme switching with consistent typography and color palettes.
- **Local Persistence**: Fast and secure on-device local storage.

---

## 🚀 Tech Stack

- **Framework**: [React Native](https://reactnative.dev/) / [Expo](https://expo.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo Go](https://expo.dev/go) app on your mobile device (iOS/Android) or an emulator

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jyoti-kumbhar/Expense-tracker.git
   cd Expense-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```

---

## 📦 Building Standalone APK

To build a standalone production APK using EAS Cloud:

```bash
npm run build:prod:apk
```
